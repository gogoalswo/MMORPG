# 클라이언트 UI / HUD

## 무엇

3D 위에 얹히는 DOM 오버레이. 이름표, 피해 숫자, 액션바, 창들.

## 어디

| 파일 | 역할 |
|---|---|
| `packages/client/index.html` | `#game`(캔버스) / `#overlay` / `#stats` / `#help` |
| `packages/client/src/ui/style.css` | 전부. 레이아웃·테마·모바일 |
| `packages/client/src/ui/*.ts` | 창 하나당 클래스 하나 |
| `packages/client/src/ui/minimap.ts` | **미니맵** — 2D 캔버스, 존 전체를 한 장에 |
| `packages/client/src/ui/skillDebug.ts` | **스킬 디버그 목록** (왼쪽) — 테스트 스위치가 켜져 있을 때만 |
| `packages/client/src/ui/godMode.ts` | **무적 단추** (왼쪽, 스킬 목록 위) — 테스트 스위치가 켜져 있을 때만 |
| `packages/client/src/scene/clickMarker.ts` | **클릭 이동 표시** — 누른 자리 바닥에 찍히는 고리 |
| `packages/client/src/main.ts` | 배선. 모든 콜백이 여기서 이어진다 |

## 규칙

### 오버레이 ★
`#overlay` 는 `pointer-events: none` 이다. 3D 클릭이 UI 를 통과해야 하기 때문이다.

**`pointer-events` 는 상속되는 속성이다.** 그래서 눌러야 하는 창은 CSS 에서
하나씩 `pointer-events: auto` 로 다시 켜야 한다. 목록에 없으면 화면에 멀쩡히
보이면서 눌리지 않는다 — PC 는 단축키로 가려지지만 폰에서는 그대로 조작 불가가 된다.

지금 켜 둔 것: `.actionbar .autohunt .autorange .hudbtns .npc-prompt .npc .bag .sb .gate .craft .death`

장식(이름표, 피해 숫자, 상태바, `#stats`)은 꺼진 채로 둔다.

### 창 여는 버튼 (`hudButtons.ts`)
화면 오른쪽 위의 **가방 · 스킬 · 채팅** 세 버튼이다.

이 셋은 오랫동안 단축키(`I` `K` `Enter`)로만 열렸다. 키보드가 없는 폰에서는
아이템을 끼는 것도, 스킬을 배우는 것도, 말을 거는 것도 불가능했다 —
게임의 절반이 잠겨 있었다.

- 버튼은 단축키와 **같은 함수**를 부른다 (`bag.toggle()` 등). 두 벌로 만들면
  한쪽만 고치게 된다.
- 버튼에 단축키를 같이 적어둔다. 한 번 눌러본 사람은 다음부터 키를 쓴다.
- 창은 자기 `✕` 로도 닫히므로 버튼 쪽에서 상태를 알 방법이 없다. 매 프레임
  물어보되 **바뀐 것만** DOM 을 건드린다 (`HudButtons.update`).
- 폰에서는 창(`.bag` `.npc` `.sb` `.gate`)이 이 버튼 아래(`top: 64px`)에서 시작한다.

### 미니맵 (`minimap.ts`) ★
오른쪽 위 창 버튼(`.hudbtns`) 바로 아래. 한 변 148px(폰 96px)의 둥근 2D 캔버스다.

- **존 전체가 한 장에 들어간다.** 주변만 확대해 보여주는 쪽이 흔하지만, 존이
  92×92 로 작고 알고 싶은 건 "이 사냥터 어디쯤이고 몬스터가 어느 쪽에 몰렸나" 라서
  전체를 보여주는 편이 쓸모 있다. 배율은 걸어갈 수 있는 범위(`zoneHalfSize`, ±42)에 맞춘다.
- **카메라가 돌면 같이 돈다.** 고정해 두면 화면에서 오른쪽에 있는 몬스터가 미니맵에서는
  오른쪽 위에 찍혀 매번 머릿속에서 돌려야 한다. 돌리면 존 경계(사각형)가 기울어 보이는데,
  둥근 테두리 안이라 그게 오히려 방향을 알려 준다. 각은 `rig.yawAngle` 을 그대로 받는다.
- **`ctx.rotate` 를 안 쓴다.** 캔버스 변환을 쓰면 배율까지 같이 먹어서 **점 크기와 선
  두께가 존 크기를 따라 변한다.** 자리만 손으로 돌리고(cos/sin) 크기는 픽셀로 둔다.
- 색은 **이미 쓰던 것과 맞춘다** — NPC 노랑(`#ffdf3d`), 차원문 파랑(`#8fd0ff`)은
  이름표와 같은 값이다. 다른 데서 배운 색을 여기서 다시 배우게 하지 않는다.
  몬스터는 붉은 점, 다른 사람은 연두 점, 나는 **보는 쪽이 뾰족한 삼각형**이다
  (점으로 두면 어디를 향하는지 모른다).
- 차원문·NPC 는 서버가 안 보내준다. **존 정의**(`ZoneDef.gate` / `.npcs`)에서 읽는다.
- 몬스터·플레이어는 **화면에 그려지는 자리**(보간된 것)를 쓴다. 충돌용 `solids()` 와
  반대인데, 저쪽은 서버와 계산을 맞춰야 하고 이쪽은 눈에 보이는 것과 맞아야 한다.
- 누를 일이 없으므로 `pointer-events` 는 꺼 둔 채로 둔다 (3D 클릭이 통과해야 한다).
- 상태를 안 들고 있다 — 그리는 값이 전부 `main.ts` 에서 온다. 배열은 다시 쓴다
  (매 프레임 새로 만들면 그만큼 쓰레기가 쌓인다).

### 스킬 디버그 목록 (`skillDebug.ts`)
화면 왼쪽, `#stats` 아래. 그 직업 스킬을 전부 세로로 늘어놓고 **누르면 바로 쏜다.**

- 액션바는 4칸이라 그 이상은 스킬창(K)에서 갈아 끼워야 한다. 이펙트나 판정을 볼 때는
  그 왕복이 확인보다 오래 걸려서 만들었다. **배우지도, 장착하지도 않고** 나간다.
- **서버도 같이 풀어야 동작한다** — `handleSkill` 이 평소에는 액션바에 올라간 것만
  받는다. `SKILL_UNLOCK_ALL` 이 켜져 있을 때만 그 검사를 건너뛴다 ([skills.md](skills.md)).
- **스위치가 꺼지면 아예 안 보인다.** 테스트 도구가 실제 플레이 화면에 남으면 그때부터
  버그다. 폰에서도 숨긴다 — 좁은 화면을 테스트 도구가 차지할 이유가 없다.
- `.skilldbg` 는 `pointer-events: auto` 목록에 들어간다 (눌러야 하므로).

### 무적 단추 (`godMode.ts`) ★
화면 왼쪽, 스킬 디버그 목록 바로 위. 누르면 **무적 모드**가 켜지고 노랗게 바뀐다.

- **맞아 가며 봐야 하는 것**을 확인할 때 쓴다 — 몬스터 공격 동작, 피격 연출,
  보스 범위 공격 같은 것. 안 죽으니 죽음 화면과 부활 대기 5초를 왕복하지 않는다.
- **켜졌는지는 서버가 정한다.** 단추는 누를 때 제 색을 바꾸지 않고, 서버가
  `godmode` 로 돌려준 값만 그린다. 스위치(`GODMODE_ALLOWED`)가 꺼져 있으면 서버가
  무시하므로, 미리 켜 두면 안 켜진 것을 켜졌다고 보여주게 된다.
- **체력만 안 깎인다. 맞은 것 자체는 그대로 온다** (`hit` 의 `amount: 0`).
  몬스터 공격 동작이 `hit` 으로 도는 구조라, 여기서 막으면 동작을 보려고 켠 무적이
  동작을 못 보게 만든다 → [combat.md](combat.md). 숫자 `0` 은 안 띄운다.
- 색으로 갈린다(노랑). 글씨만 바뀌면 난전 중에 지금 켜져 있는지 못 알아본다.
- **존을 옮기면 룸이 새로 생겨 서버 쪽이 꺼진다.** ★ 무적은 룸에 붙어 있다
  (`ZoneRoom.godmode` 는 세션 집합이다). 그래서 `Connection.join` 이 룸을 잡을 때마다
  **단추를 먼저 꺼짐으로 되돌리고**(`onGodMode(false)`), 사람이 마지막으로 누른 값이
  켜짐이면 `godmode` 를 다시 보낸다 — 켜졌는지는 그 답으로만 그린다.
  되돌리는 게 핵심이다: 안 되돌리면 차원문을 지난 뒤 **단추만 노랗게 남고 실제로는
  안 무적**이라, "눌렀는데 무적이 안 된다"가 된다. 실제로 그 버그가 있었다.
- 스위치가 꺼지면 아예 안 보이고, 폰에서도 숨긴다 (스킬 디버그 목록과 같은 규칙).

### 이름표 / 피해 숫자
- 3D 텍스트가 아니라 HTML 오버레이다. 폰트가 또렷하고 드로우콜을 안 늘린다.
- 카메라 뒤 / 70유닛 초과는 숨긴다 (DOM 갱신 비용).
- 이름은 거의 안 바뀌므로 달라졌을 때만 DOM 을 건드린다. 강조(`is-target`)도 마찬가지.
- **종류 세 가지** (`NameplateTarget.kind`, 붙일 때 한 번만 정한다):

  | kind | 누구 | 이름 색 | HP바 |
  |---|---|---|---|
  | `unit` (기본) | 플레이어 · 몬스터 | 흰색 `#fff` | 있음 |
  | `npc` | 마을 사람 | **노란색 `#ffdf3d`** (직함 `#e8cf6a`) | 있음 |
  | `portal` | 차원문 안내 글씨 | 파란색 `#8fd0ff` | 없음 |

  **NPC 를 노랗게 뗀 이유**: 마을 사람은 고유 외형(`NPC_LOOKS`)을 입고 있지만,
  그것만으로는 사람이 몰린 마을에서 누가 유저인지 알아볼 수 없다. 색이 가장 빨리
  읽힌다. 물고 있는 대상(`is-target`)도 금색이라 비슷해 보일 수 있는데, 그쪽은
  글로우가 함께 붙고 몬스터에게만 달린다.
- 피해 숫자 종류: `deal` / `take` / `kill` / `gain`, 치명타는 `is-crit`
  (색은 그대로 두고 키운다 — 색까지 바꾸면 처치와 헷갈린다).

### 모바일 (`@media (max-width: 760px)`)
- 액션바(4칸)와 자동 사냥 버튼을 한 줄에 두면 화면 밖으로 밀려난다.
  폰에서는 자동 사냥을 **오른쪽 위**로 세우고, 아래에서부터
  상태바 → 액션바 → 자동사냥 → 범위 → 채팅 순으로 쌓는다.
- 창(가방·NPC·스킬·차원문·제작)은 좌우 8px 여백만 두고 화면 폭을 채운다.
- **제작창은 `.hudbtns` 에 넣지 않는다.** 그 버튼들은 어디서나 열리는 창(가방·
  스킬·채팅)이고, 제작은 서버가 대장간 거리를 다시 재기 때문에 아무 데서나
  누르면 "너무 멉니다" 만 나온다. 들어가는 길은 대장간 앞 `F` 하나다.
  차원문은 20줄을 손가락으로 훑으므로 줄 높이를 키운다(`@media (pointer: coarse)`).
- `#help` 는 숨긴다 (휠·Enter·숫자키가 없다).
- `@media (pointer: coarse)` 에서 작은 스위치를 키운다 (`A` 15px → 22px).
- `touch-action: manipulation` — 두 번 두드리면 확대되는 동작과 눌림 지연 제거.

### 렌더 루프 주의 ★
`requestAnimationFrame` 은 화면이 가려지면 0~1Hz 다. 그래서:
- rAF 안에서만 하는 일(이름표 위치, 쿨타임 표시, 프롬프트 갱신)은 창이
  가려지면 멈춘다. **버그가 아니다.** 이걸로 여러 번 오진했다.
- 오래 안 그린 뒤에는 쌓인 시각 효과를 버린다(`dropStaleVisuals`, `STALL_MS`).
- 계속 돌아야 하는 로직은 서버에 둔다.

### 클릭 이동 표시 (`scene/clickMarker.ts`) ★
- 땅을 눌러 이동하면 그 자리에 **하늘색 고리가 퍼졌다 조여들며** 0.5초 동안 남는다.
  카메라가 멀고(거리 40) 자동 사냥 중에는 서버가 걷기 시작할 때까지 한 박자 비어서,
  누른 게 먹혔는지 화면만 봐서는 알 수 없었다.
- **누른 순간에는 무조건, 끌고 다니는 동안에는 0.5초에 한 번**만 찍는다
  (`MARK_REPEAT_MS`, `main.ts`). `Input.onGroundPoint` 의 두 번째 인자 `pressed` 가
  누른 프레임을 가려낸다 — 이 콜백은 끄는 동안 초당 60번 오는데 그때마다 다시 찍으면
  연출이 계속 처음으로 돌아가 오히려 멈춰 있는 것처럼 보인다.
- 간격은 표시 길이(`clickMarker.ts` 의 `DURATION`, 0.5초)와 **같은 값으로 맞춰 뒀다.**
  한 번이 끝나는 자리에서 다음이 찍혀 잘리지도 비지도 않는다. 둘은 같이 움직여야
  하는 값이라 한쪽만 바꾸면 고리가 조여들다 잘리거나(간격이 짧을 때) 뚝뚝 끊긴다.
- 몬스터를 눌렀을 때는 안 찍는다 (그쪽은 이동이 아니라 지목이고, 발밑 금색 고리가 따로 있다).
- 표시는 **언제나 하나뿐이다.** 메시 두 장(고리·가운데 점)을 만들어 두고 스케일과
  투명도만 건드린다. 풀도 수명 목록도 없는 것이 `skillFx` 와 다른 점이다.
- 밝기는 **빠르게 켜고 끝에서만 끈다.** `1-t` 로 처음부터 흐려지게 두면 가장
  작아진(=가장 잘 보여야 할) 순간이 가장 투명해서 어느 프레임에도 안 걸린다
  (`skillFx.ts` 밝기 곡선에서 한 번 겪은 것).

### 조작
- 좌클릭: **몬스터면 지목**(겨누기만 — 걸어가지 않는다), 아니면 그 지점으로 이동.
  누르고 있으면 계속 따라간다. 누른 자리에는 고리가 한 번 찍힌다(위).
  지목을 풀려면 `Esc` (땅 클릭으로는 안 풀린다).
  지목한 놈은 **이름표가 금색으로 밝아지고 발밑에 금색 고리**가 생긴다
  ([auto-hunt-and-targeting.md](auto-hunt-and-targeting.md)).
- **이동은 클릭으로만 한다.** WASD·방향키 이동은 2026-09-11 에 뺐다 (`input.ts` 에 `moveAxis` 가 없다).
- Q/E 카메라 회전, 휠 줌, **1~4 = 액션바 1~4번 칸**(`SKILL_BAR_SIZE` 만큼만 받는다), F 말걸기, I 가방, K 스킬창, Enter 채팅.
- **키보드가 없어도 다 된다.** 가방·스킬·채팅은 오른쪽 위 버튼, 말걸기는 `F` 버튼,
  자동 사냥·스킬은 액션바 버튼으로 연다. 몬스터를 클릭하면 겨누고, 액션바를
  누르면 그쪽으로 나간다.
- Space 기본 공격은 남아 있지만 안내문에서는 뺐다 (클릭이 주 조작).

## 손댈 때

- 새 창을 만들면 **CSS 의 `pointer-events: auto` 목록에 추가**하고,
  모바일 media query 에도 넣는다.
- `main.ts` 배선을 잊지 말 것. 창 클래스의 `onXxx` 콜백을 안 이으면 버튼이
  조용히 아무 일도 안 한다.
