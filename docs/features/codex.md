# 장비 도감

## 무엇

가방의 장비를 **넣어(소모)** 칸을 채우면 능력치가 % 로 붙는다. 칸은 **등급 7 × 부위 6 × 강화 +0 ~ +9 = 420칸**,
창은 등급마다 탭 하나(일반 ~ 태초)에 부위 여섯 줄 × 강화 열 칸이다.

요청 (2026-10-01): "도감 만들자. 각 등급 0강부터 9강까지 등록할 수 있는 도감 만들어. 파츠별로 도감 만들어.
그리고 탭 만들어서 일반부터 태초등급까지 만들어". 등록하면 소모 · 칸마다 능력치 · 메뉴 단추는 바르코 그림 —
셋 다 물어서 고른 안이다.

## 규칙

### 칸과 등록 ★

- 칸 주소는 **아이템 id(등급·부위가 하나로 정해진다, 예 `g3_w`) + 강화**. 장부에는 `codex = { id: 비트 }` 로 둔다
  (+0 = 1, +1 = 2, … +9 = 512). 칸 주소를 따로 만들지 않은 이유 — 42종 카탈로그가 이미 등급 × 부위다.
- **등록하면 그 장비 하나가 가방에서 없어진다.** 겹친 칸이면 개수만 하나 준다.
- **끼고 있는 장비는 안 받는다** — 가방만 뒤진다. 몸에서 벗겨져 사라지면 되돌릴 수 없다.
- **넣을 장비는 창에서 고른다** (2026-10-01 요청 "등록할 때 어떤 아이템 넣을건지 선택하는 UI도 만들어").
  요청은 고른 **가방 번호**를 같이 싣고, 장부가 그 칸이 이 등급·부위·강화가 맞는지 다시 본다 — 그사이 가방이
  바뀌어 다른 것이 서 있으면 넣지 않는다("고른 … 이 가방에 없습니다"). 번호가 -1 이면 **옵션 줄(1·2·3차 합)이
  가장 적은 것**.
- 이미 찬 칸 · 가방에 없는 것은 거절(알림만). 표에 없는 id · 강화 범위 밖은 조용히 무시.
- **잠근 장비는 안 받는다** (2026-10-02) — 고른 칸이 잠겼으면 거절, 자동 고르기(-1)는 건너뛴다. 창도 잠근 것을
  "가방에 있음" 으로 안 세고 고르기 창에 안 띄운다 → [inventory-equipment.md](inventory-equipment.md) "잠금".
- 왜 소모인가: 강화가 실패하면 부서지는 게임이라 같은 등급 여벌이 계속 나온다 — 그 여벌을 쓸 곳이다.

### 수치 ★★

부위마다 올리는 능력치 하나, **능력치마다 부위 둘** — 셋이 같은 크기로 자란다.

| 부위 | 능력치 |
|---|---|
| 무기 · 목걸이 | 공격력 |
| 갑옷 · 투구 | 방어력 |
| 신발 · 반지 | 체력 |

**칸 몫 = 등급 몫 × (강화 + 1)** %:

| 등급 | 등급 몫(+0) | +9 | 한 부위 10칸 합 |
|---|---|---|---|
| 일반 | 0.01 | 0.1 | 0.55 |
| 고급 | 0.02 | 0.2 | 1.1 |
| 희귀 | 0.03 | 0.3 | 1.65 |
| 영웅 | 0.05 | 0.5 | 2.75 |
| 전설 | 0.08 | 0.8 | 4.4 |
| 초월 | 0.12 | 1.2 | 6.6 |
| 태초 | 0.2 | 2.0 | 11 |

- **다 채우면 능력치마다 +56.1%** (등급 합 28.05 × 부위 둘).
- 강화를 ×(강화+1) 로 크게 준 이유: 실패하면 부서져 +9 까지 닿기가 매우 어렵다 — 높은 칸이 값어치를 해야 한다.
- 처음 안은 `× (1 + 0.1 × 강화)` 였는데 소수 둘째 자리에서 0.06 · 0.06 처럼 **같은 값이 겹쳐서** 바꿨다.
  지금 공식은 늘 0.01 의 배수다.
- 바꾸려면 `CODEX_GRADE_VALUE` 를 고치고 `codex.test.ts` 의 56.1 과 이 표를 같이 고친다.

### 보너스는 따로 곱한다 ★

```
최종 = 기본(레벨) × (1 + 장비 %) × (1 + 헬스 %) × (1 + 도감 %)
```

헬스와 같은 이유 — 장비 % 에 더하면 태초 풀셋 앞에서 안 보인다 ([fitness.md](fitness.md)).
캐릭터 정보 창은 증가 줄을 세 몫을 곱한 합계 % 로 적고, 그 아래 풀이 줄 `(장비 N% × 헬스 N% × 도감 N%)` 에
도감 몫(소수 둘째 자리)을 적는다 ([fitness.md](fitness.md)). **0% 인 몫은 풀이 줄에서 뺀다**(셋 다 0 이면 줄이 없다).

### 창 (`codex_panel.gd`) ★

결은 헬스 창과 같다 (돌판 틀 `ui_dungeon_card` · 전체 화면 · 금빛 탭 · 오른쪽 칸 · 청록 단추).

```
 일반  고급  희귀•  영웅  전설•  초월  태초                                     X
 ──────────────────────────────────────────────────────┬──────────────────
          +0   +1   +2   +3   +4 … +9                   │    획득 효과
 무기     [■]  [■]  [■]  [□•] [ ] … [ ]                  │ ◆ 공격력 +0.18% (희귀 +0.18%)
 공격력                                                  │ ◆ 방어력 …
 갑옷 · 투구 · 신발 · 목걸이 · 반지 …                      │   희귀 6 / 60 · 전체 6 / 420
                                                        │    선택한 칸
                                                        │ [그림] 흑철 건틀릿 +3
                                                        │ 공격력 +0.12%
                                                        │ 가방에 1개 — 하나를 넣습니다
                                                        │ [        등록        ]
```

- 탭 글자는 **등급 색**(고른 탭만 밝게 + 금빛 밑줄, 폭 112). 그 등급에 넣을 수 있는 칸이나 자동 등록으로 새로 찬 칸이 있으면 탭에 빨간 점.
- 칸 셋 — **찬 칸**(그림 또렷 · 등급 색 테) · **넣을 수 있는 칸**(그림 반투명 · 청록 테 · 빨간 점) · **빈 칸**(흐림).
  칸 그림은 장비 아이콘(`{부위}_g{등급}`)을 그대로 쓴다 — 새로 그리지 않았다.
- 칸을 직접 누르기 전에는 **넣을 수 있는 첫 칸**이 저절로 골라진다 — 하나 넣으면 다음 칸으로 넘어간다.
- 오른쪽 칸의 [등록] 은 바로 넣지 않고 **고르기 창**을 연다 (아래). 그 왼쪽은 [자동 등록 설정](아래 "주울 때 자동 등록") —
  원래 [자동 등록](아래 "자동 등록") 자리였는데 2026-10-02 에 바꿨고 [자동 등록] 은 **숨겼다**.
  그 위 한 줄의 [강화] 는 아래 "강화 단추".
- 0% 는 "0" 으로 적는다 — `String.num(0.0, 2)` 가 "0.0" 을 돌려 "방어력 +0.0%" 로 찍혔다.
- 획득 효과는 도감 전체, 괄호(하늘색)는 이 등급 몫.
- 장부가 바뀌면(`codex` · 가방의 id·강화·개수) `refresh` 가 알아채 다시 그린다. 가방은 옵션까지 문자열로 만들지
  않는다(`_bag_key`).
- 창은 차원문 · 던전 · 헬스 창과 **같은 층(10)** — 하나를 열면 나머지를 닫는다.

### 고르기 창 (`codex_picker.gd`) ★

요청 (2026-10-01): "도감 등록할 때 가방에서 선택하는 UI를 따로 만들어. 지금 보면 2,3차 옵션은 안 보이자나".
그 전에는 오른쪽 칸 안 목록이 1차(`options`)만 한 줄로 이어 적었다 — 2차(`options2`) · 3차(`options3`)는 칸이 따로라 빠졌다.

```
 ┌──────────── 등록할 장비 선택 — 흑철 건틀릿 +3 ────────────┐
 │ ┌──────────────────────┐ ┌──────────────────────┐ │   두 열 칸, 끌어서 내린다(DragScroll)
 │ │[그림] 흑철 건틀릿 +3   │ │[그림] 흑철 건틀릿 +3   │ │   고른 칸은 금빛 테
 │ │ 1차  비어 있음         │ │ 1차  치명타 +6%        │ │   차수마다 줄 — 옵션이 없으면 "비어 있음"
 │ │ 2차  비어 있음         │ │ 2차  아이템 드랍률 +9% │ │   크리스탈로 붙는 2차는 금빛
 │ │ 3차  비어 있음         │ │ 3차  비어 있음         │ │
 │ └──────────────────────┘ └──────────────────────┘ │
 │ 넣은 장비는 가방에서 사라집니다       [ 취소 ] [ 등록 ] │
 └──────────────────────────────────────────────────┘
```

- 도감 창의 맨 뒤 자식이라 모든 것 위에 뜬다. 뒤는 어둡게 덮고 누름을 막는다. 결은 메뉴 판과 같은 어두운 판 + 얇은 금테.
- 처음엔 **옵션 줄(1·2·3차 합)이 가장 적은 것**이 골라져 있다 — 장부 기본과 같은 셈(`Items.option_lines`).
- [등록] → `picked(가방 번호)` → 도감 창이 `register_requested(id, 강화, 번호)` 를 낸다. [취소] · 도감 창 닫기는 그냥 닫는다.
- 차수 말("N차" · "비어 있음")은 크리스탈 창과 같다.
- 확인 사진: `npm run shot:godot -- codex_pick` → `logs/shot_codex_pick.png`.

### 자동 등록 ★

요청 (2026-10-02): "도감에 자동 등록 버튼 만들어". 오른쪽 칸 맨 아래 `[자동 등록] [등록]` 한 줄 (창 높이를 늘리지 않는다).
★ **같은 날 숨겼다** ("자동 등록 설정 버튼을 자동 등록 버튼 위치로 옮기고, 기존 자동 등록 버튼은 숨김 처리 해") —
단추는 `visible = false` 로 남고, 판정(`codex_register_all`) · 확인 창 · 시험은 그대로다. 되살리려면 그 한 줄만 지운다.

- **등급을 가리지 않고** 넣을 수 있는 칸 전부를 채운다 — 어느 탭에 있든 같다. 탭에 빨간 점이 하나도 없으면 단추가 꺼진다.
- 칸마다 하나, 같은 칸의 장비가 여럿이면 **옵션 줄(1·2·3차 합)이 가장 적은 것** — 하나 넣기의 기본(-1)과 같은 셈이다.
  **잠근 장비는 건너뛴다** — 잠근 것만 있으면 단추가 꺼진다.
  셈은 `Codex.auto_picks(codex, bag)` 하나 — 장부(`Ledger.codex_register_all`)와 확인 창이 같이 쓴다.
- 누르면 바로 넣지 않고 **고르기 창을 확인 창으로** 연다(`CodexPicker.open_all`) — 들어갈 장비를 전부 금빛 테로
  늘어놓고(1·2·3차까지 보인다) 제목 "자동 등록 — N칸에 넣습니다". 칸을 눌러도 고르지 않는다. [등록] → `picked_all`
  → `register_all_requested` → `codexRegisterAll` → 서버 op `codex_register_all`(인자 없음).
- 장부가 고르기를 **다시 한다** — 그사이 가방이 바뀌었으면 바뀐 가방으로 센다. 뒤 번호부터 떼서 번호가 밀리지 않는다.
- 칸마다 `codexResult` 를 내고(지금 탭의 칸이 튕긴다), 알림은 한 줄 `도감 자동 등록 — N칸 · 공격력 +x% · …`.
- 왜 확인을 거치나: 넣은 장비는 사라지고, 한 칸에 하나뿐이면 옵션이 좋아도 그게 들어간다.

### 강화 단추 ★

요청 (2026-10-02): "도감에서 강화 버튼 만들어. 도감 목록 누르면 강화 버튼 활성화 시키고 버튼 누르면 해당 장비를
선택하고 목표 등급 자동 선택 된 상태로 창을 띄워". 오른쪽 칸 `[자동 등록] [등록]` **위에 한 줄을 따로** —
셋을 한 줄에 두면 340 칸에 안 들어간다(단추 여백 28 × 2). 높이는 위의 빈 칸(gap)이 내줘서 창은 그대로다.

- **칸을 직접 눌러야 켜진다** — 저절로 골라진 첫 칸(`_auto_pick`)에서는 꺼져 있다. 찬 칸, 같은 장비가 목표 아래에
  없는 칸도 꺼진다.
- 고르는 장비 — `Codex.enhance_source(bag, id, 강화)`: **같은 장비(id)를 칸의 강화 단계 아래에서**, 목표에
  **가장 가까운 것**(두드릴 횟수가 적다), 같으면 옵션 줄이 적은 것(등록 기본과 같은 셈 — 좋은 것을 남긴다).
  **잠근 것은 뺀다** (강화를 거절한다). **가방만 본다** — 끼운 것을 올리면 도감에 넣으려고 또 벗어야 한다.
- 누르면 `enhance_requested(가방 번호, 칸의 강화)` → `game.gd` `_open_enhance_from_codex` 가 강화 팝업을
  **다중 강화 · "같은 아이템" 목록 · 목표 = 칸의 강화 · 목표 아래 같은 장비 전부 담김**으로 연다
  (`open` → `set_goal` → `pick_mode("multi")` → `pick_filter("item")` → `pick_all()` — 목표를 먼저 잡아야 목록이
  목표 아래만 거른다. 잠근 것 · 목표 이상은 목록에 안 나와 안 담긴다. 칸은 최대 14). 처음엔 단일이었는데 같은 날
  "기본 강화 탭이 다중강화로 되고, 동일한 아이템이 다 담긴 상태가 되면 좋겠어" 로 바꿨다. 강화 팝업은 `_ui_root`(도감 층 10
  아래)라 **도감을 잠시 감춘다.** X 로 닫으면(`closed`) `_back_to_codex` 가 도감을 **같은 탭 · 같은 칸**으로 다시 연다.
  가방 · 크리스탈 단추나 다른 길로 강화 창을 열면 돌아가지 않는다(`_enhance_from_codex` 를 내린다).
- 테스트: `codex_test`(고르는 규칙 · 꺼짐 · 요청) · `ui_test` `_case_codex_enhance`(창 · 대상 · 목표 · 도감으로 돌아오기).

### 주울 때 자동 등록 ★★

요청 (2026-10-02): "도감창에 아이템 자동 등록 활성화 기능 만들어. 등급별로 설정할 수 있도록 만들고, 해당 기능이
활성화 되면 아이템을 습득했는데, 도감에 등록 할 수 있으면 바로 등록하고, 강화 수치가 부족하면 바로 강화를 1단계부터
쭉~ 해서 해당 단계까지 강화 성공하면 등록 되게 만들어. 그리고 등록 되면 레드닷 표시해놓고."
위의 [자동 등록] 단추(가방에 있는 것을 한 번에)와는 **다른 것**이다 — 이건 **주울 때** 장부가 저절로 한다.

```
 오른쪽 칸 맨 아래  [ 자동 등록 설정 ][ 등록 ]        ← 옛 [자동 등록] 자리 (처음엔 탭 줄 오른쪽이었다)
  ┌──────────────────── 자동 등록 설정 (폭 860) ────────────────────┐
  │ ◆ 주운 장비를 바로 도감에 넣습니다 — …                              │
  │  일반•  고급  희귀•  영웅  전설  초월  태초                          │ ← 등급 탭 (켠 등급은 금빛 점)
  │  자동 등록                                       [ ON ][ OFF ]    │ ← `SettingsPanel.make_switch`
  │  아이템 종류 — 활성화 된 종류만 자동으로 등록합니다                    │
  │  [무기][갑옷][투구][신발][목걸이][반지]                              │ ← 켜면(밝음) 넣는다
  │  1차 옵션 — 활성화 된 옵션만 자동으로 등록합니다                        │
  │  [치명타][치명타 데미지][체력][방어력 관통][아이템 드랍률]              │ ← 켜면(밝음) 넣는다
  │                                                          (X)    │
```

- **등급마다 종류(부위)를 고른다** (같은 날 요청: "등급마다 아이템 종류도 선택할 수 있게") — 장부 칸 `codex_auto` 는
  `{ "등급": [넣을 부위, …] }`(처음엔 빈 사전 = 다 끔). 요청은 **등급 하나씩** `codexAutoGrade {grade, slots}` →
  `set_codex_auto_grade`(서버 `"iw"`) · 저장에 남는다. 목록이 비면 그 등급은 꺼진다.
  - 등급 스위치 ON → 그 등급의 **전 부위**, OFF → 비운다. 칩을 누르면 그 부위만 넣고 뺀다(마지막 하나를 빼면 꺼진다,
    꺼진 등급의 칩을 누르면 그 부위만 켠 채 켜진다). 꺼진 등급의 칩은 흐리게 그린다.
  - 다듬기 `Ledger.clean_codex_auto` — 표에 있는 등급 · 부위만, 부위는 표 순서. **첫 판(같은 날 아침)의 모양 `[등급, …]`
    은 그 등급의 전 부위로 읽는다** — 그 사이 저장한 기기가 있다.
- **1차 옵션도 고른다 — 등급마다, 활성화된 옵션만 넣는다** ★ (같은 날 요청이 셋 이어졌다: "치명타 옵션이 있을 경우 등록
  안 되게 막는거야"(전 등급 공통 막기) → "등급마다 옵션 설정할 수 있게. … 활성화 된 옵션은 자동으로 등록하지 않습니다"
  (등급별 막기) → **"옵션도 활성화 된 옵션만 자동등록하는걸로 바꿔"**). 이제 종류 칩과 같은 뜻이다 — 칩을 **켜면(밝음)
  그 옵션이 1차(`options`)에 붙은 장비를 넣는다.** 켜지 않은 옵션이 붙은 장비는 그 등급이 켜져 있어도 가방에 그대로 둔다.
  - 장부 칸 `codex_auto_options` `{ "등급": [넣을 종류, …] }` · 요청 `codexAutoOptions {grade, kinds}` →
    `set_codex_auto_options`(서버 `"iw"`) · 저장에 남는다. **등급이 표에 없으면 전 옵션**(`codex_auto_option_kinds`) —
    빈 목록은 "하나도 안 넣는다" 로 그대로 남긴다(다 끈 것과 정하지 않은 것을 구분한다).
  - 등급 스위치를 ON 하면 전 부위와 **전 옵션**을 같이 켠다 — 옵션을 다 꺼 둔 채 켜면 아무것도 안 들어와 헷갈린다.
  - **옛 칸 `codex_auto_block`**(막을 옵션 — `[종류]` 전 등급 공통 또는 `{등급: [종류]}`, 같은 날 낮에만 썼다)은
    `codex_auto_options` 가 없을 때 **전 옵션 − 막은 것**으로 읽는다. 새로 정하면 옛 칸을 지운다.
- **창은 등급 탭**이다 — 일곱 등급을 줄로 늘어놓고 옵션 칩까지 넣으면 720 높이에 안 들어간다. 탭마다 `자동 등록 [ON][OFF]` ·
  종류 칩 · 옵션 칩. 도감에서 보던 등급 탭으로 열린다. 켠 등급 탭은 오른쪽 위 금빛 점. 꺼진 등급의 칩은 **값과 관계없이
  꺼진 칩(어두운 판)으로** 흐리게 그린다 — 옵션 칩은 꺼져도 넣을 옵션 값이 남아 밝은 판이 흐리게 보여 종류 칩과 색이 달랐다
  (2026-10-02 지적). 값은 남아서 등급을 다시 켜면 그대로 밝아진다.
- **닫기는 오른쪽 위 X** — [닫기] 단추는 뺐다(같은 날 요청). X 그림은 창 X 와 같은 `ui_close`(도감 창이 만들어 넘긴다).
- ★ **위에 뜨는 창은 열 때 `move_to_front()`** — 도감 창 X 는 `game.gd` `_close_button` 이 창을 다 지은 **뒤에** 맨 끝 자식으로
  붙인다. 그래서 자동 등록 설정 창·고르기 창이 떠 있어도 X 가 그 위에 그려지고 눌렸다(같은 날 지적 "뒤에 도감창 X버튼이
  눌리는 문제"). 두 창 다 열 때 맨 앞으로 올린다 — 도감 창 안에 새 겹창을 만들면 같은 줄을 넣는다.
- ★ **서버 인자 `"w"`(글자 목록)** — `"a"` 는 **숫자 목록만** 받는다. 처음엔 옵션 막기를 `"a"` 로 적어 서버에 붙으면
  `bad_args` 로 거절될 뻔했다. 부위·옵션 종류처럼 글자 목록은 `"w"` 로 적는다 (`LedgerServer._args`).
- 가방에서 무엇이 사라지는지가 바뀌므로 둘 다 **장부**다 (설정 창의 습득 등급 `loot_skip` 과 같은 길).
- **판정은 `Ledger.kill` 이 장비를 가방에 넣은 바로 뒤** (`_codex_auto`). 노리는 칸은 **지금 강화 이상에서 가장 낮은
  빈 칸**(`Codex.next_empty`):
  - 그 단계가 비었으면 바로 넣는다.
  - 찼으면 그 칸 단계까지 **한 단계씩** 두드린다 — 강화와 같은 판정(`_roll_once` → `Items.roll_enhance`)이라
    **실패하면 부서진다** (설계상 강화는 공짜 · 실패 = 파괴, 유지 없음 → [items.md](items.md)). 목표에 닿으면 넣는다.
  - 빈 칸이 없으면(그 단계 이상이 다 찼으면) 가방에 그대로 둔다. 잠근 것 · 겹친 칸은 건드리지 않는다.
- 알림 한 줄 — `도감 자동 등록 — 흑철 건틀릿 +3 (강화 3번) · 공격력 +0.12%` / `도감 자동 강화 실패 — … +1 에서 부서졌습니다`.
  `codexResult` 에 `auto: true` 가 붙는다. 강화 팝업 연출(`enhanceResult`)은 내지 않는다 — 사냥 중에 창이 뜨면 안 된다.
- **굴림이 늘어난다** — 자동 강화가 같은 `rng` 를 쓰니 켜 두면 뒤 드롭이 바뀐다. 서버·로컬이 같은 장부 코드를 돌려
  어긋나지 않는다 (끈 상태는 예전과 똑같이 굴린다).
- 왜 다음 빈 단계까지인가: "해당 단계까지" — 주운 장비는 거의 +0 이고 +0 칸은 금방 찬다. 그다음 칸을 채우려면
  어차피 올려야 한다.

#### 빨간 점 (새로 찬 칸)

- 자동 등록이 채운 칸은 장부 칸 `codex_new`(`{ 아이템 id: 강화 비트 }`, 저장에 남는다)에 적힌다.
- 빨간 점 — **메뉴의 도감 아이콘**과 **≡**(도감이 펼친 판 안에 있을 때만, `game.gd` `_refresh_status`) · 그 등급 **탭** ·
  그 **칸**(찬 칸인데 점이 있으면 새로 찬 것, 비어 있는데 점이 있으면 넣을 수 있는 것 — 둘 다 "봐라" 이다).
- 도감을 열면 새 칸이 있는 탭으로 연다(보던 탭에도 있으면 그대로).
- **그 탭을 보고 떠나면 지운다** — 다른 탭을 누르거나 창이 숨으면(`visibility_changed` — X · 다른 창 · 강화 창으로
  넘어감 모두) `seen(등급)` → `codexSeen {grade}` → `Ledger.codex_seen`(서버 `"i"`, 0 이면 전부). 연 순간 지우면
  점을 볼 틈이 없어서 떠날 때 지운다.
- 테스트: `codex_test` `_case_auto_loot`(꺼짐 · 바로 · 두드려 넣기/부서짐 40 씨앗 · 빈 칸 없음 · 잠금 · 지우기) ·
  `_case_auto_kill`(처치 200번과 이어졌나) · `_case_auto_save`(저장 · 서버 요청) · `_case_panel`(설정 창 · 점 · 떠날 때 알림).

## 손댈 때

- 장부 칸을 더했으면 `Ledger.KEYS` · `fresh` · `World.join` · `restore` · `save.gd` 를 같이 본다 (헬스와 같다).
- `World.stats_of` 인자를 바꾸면 `kill_check.gd` 도 같이 — 안 그러면 서버 처치 검증이 어긋난다.
- 등급·부위 수가 바뀌면 칸 표(`CODEX_CELLS`)와 창의 탭·줄 수가 표에서 따라온다. 강화 끝이 바뀌면 `CODEX_MAX_ENHANCE`.
- 하나 넣기 · 자동 등록 · 주울 때 자동 등록이 칸을 채우는 길은 `Ledger._codex_take` 하나다 — 칸 · 이벤트를 바꾸면 거기만 고친다.
- 강화 판정(`Items.roll_enhance` · 비용)을 바꾸면 주울 때 자동 등록도 같이 바뀐다 — 유지(keep)가 생기면 고리가 그만큼 더 돈다.
