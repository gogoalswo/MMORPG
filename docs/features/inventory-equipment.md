`weapon · armor · helmet · boots · necklace · ring` (무기·갑옷·투구·신발·목걸이·반지)

목걸이, 반지 이렇게야"). 없앤 것은 **보조(offhand)** 와 **귀걸이(earring)** 다.

### 칸 크기는 실제로 재서 센다 ★

스크롤 높이는 `칸 * 줄수 + 칸 사이 * (줄수-1)` 이고, 격자 간격도 코드에서
못박는다(`BAG_GRID_GAP`). 가로에는 세로 스크롤바 폭(`SCROLLBAR_W`)을 더한다.

**"칸" 이 얼마인지는 두 번 바뀌었다.** 옛 칸(88·74)은 안쪽 여백만큼 커져서
`CELL * 줄수` 로 잡으면 **마지막 줄이 잘렸다** (2026-09-20). 인벤토리 결 칸
(2026-09-23)은 안에 최소 크기를 가진 것이 없어 **`CELL` 이 곧 바깥 크기**다 —
여백을 또 더했더니 격자 아래가 한 줄 가까이 비었다. 둘 다 찍어서 알았다.
지금 `CELL = 58`, 8줄이라 인벤토리 창이 670 높이다.

### 칸 목록은 끌어서 내린다 ★

칸마다 칸 전체를 덮는 `hit` 단추가 있어서 **끌기를 단추가 다 먹었다** — 휠로만
내려가고 끌어서는(폰에서는 손가락으로) 안 내려갔다 (2026-09-24 지적). 엔진의
`ScrollContainer` 끌기는 터치 화면일 때만 켜지고, 켜면 흉내 낸 마우스와 겹쳐
두 배로 내려간다. 그래서 차원문 목록(`GatePanel._on_list_input`)과 같은 방식이다:

- 한 벌만 둔다 — `DragScroll.attach(목록, 격자, 칸 사이)` 를 붙이면 된다. 지금
  **가방(`_bag_drag`)·스킬 목록(`_skill_drag`)·강화 목록(`EnhancePopup.list_drag`)**.
- 격자에 들어오는 **칸은 흘려보내고(PASS) 칸 안의 것은 전부 비킨다(IGNORE)**
  (`_let_through`, `child_entered_tree` 에서 — 칸을 나중에 채워도 자동이다).
  처음에는 `hit` 만 비켰는데, **칸 자체(`PanelContainer`, 기본 STOP)가 입력을
  멈춰서** 목록에 안 닿았다 — 화면에서는 선택까지 죽었다 (2026-09-24). 테스트가
  `on_input` 을 직접 불러서 이 길을 못 봤다 → 지금은 창에 입력을 넣는다
  ([verification.md](verification.md) "손댈 때").
- 목록이 직접 받는다(`on_input`). **데드존(`GatePanel.DEADZONE`, 14px)을 넘겨 끌면
  스크롤, 그 자리에서 떼면** 그 칸(`cell_at`, 감춘 칸은 건너뜀)의 `hit.pressed` 를
  낸다 — 누른 칸과 뗀 칸이 달라도 취소다. 휠은 `ScrollContainer` 에 넘기고
  손가락 이벤트는 삼킨다. 창을 닫을 때 `forget()` 으로 누르던 것을 잊는다.
- 장비 칸·담은 칸(강화)은 스크롤이 없어 단추가 그대로 받는다.
- 스킬 목록은 지금 직업 스킬이 두 줄 안에 다 들어가 끌 거리가 없다 — 늘면 그대로 된다.
- 확인: `tests/ui_test.gd` 의 `_case_bag_drag` (`_drag_list` · `_tap_cell` — `push_input` 으로 창에 넣는다).

### 창 레이아웃 ★
2026-09-23 요청 — 사용자가 인벤토리 그림 한 장을 주며 **"이런 느낌으로. 아이템을
클릭하면 왼쪽처럼 상세 정보. 장착창은 왼쪽으로 따로 창을"**.
```
┌ 장비 LV.1 ───── X┐              ┌ 전설 ───── X┐┌ 인벤토리 ──────── X┐
│ [무기] 몸 [신발] │              │ 전설 반지 +1 ││ [][][][][]  [전체] │
│ [갑옷]    [목걸이]│  (게임 화면)  │ 반지·Lv.121 ▣││ [][][][][]  [무기] │
│ [투구]    [반지] │              │ 보유 중      ││ ... 8줄     [방어구]│
│ 공격력 · 방어력  │              │ 아이템 정보 ─ ││             [장신구]│
│ 체력 · 치명타 …  │              │ 등급   전설  ││ 소지품 3/200 [장비][정렬]│
│                  │              │ …    [장착]  ││ (동전) 1,240       │
└──────────────────┘              └─────────────┘└────────────────────┘
```
- **셋을 한 가로 상자에 넣고 가운데에 늘어나는 빈칸을 둔다** (`_build_bag_panel`).
  장비는 왼쪽 끝, 인벤토리는 오른쪽 끝에 붙고, 상세는 인벤토리 바로 왼쪽이다.
  앵커만으로 자리가 잡혀 해상도가 바뀌어도 양 끝에 남는다. 세 창의 높이는
  상자가 맞춘다(가장 큰 인벤토리 높이). `ui_test` 가 자리·겹침·화면 안을 잰다.
- **가방 단추는 인벤토리와 장비 창을 같이 연다.** 장비 창은 자기 X 로 따로 닫고
  인벤토리의 **"장비"** 단추로 다시 연다(`_toggle_gear`). 인벤토리 X 는 셋 다 닫는다.
- **상세 창은 칸을 눌러야 뜬다.** 빈칸을 누르거나 X 를 누르면 닫힌다 (`_pick_bag`).
- **고른 가방 칸을 한 번 더 누르면 장착·사용한다** (2026-09-23 요청). 칸을 고르면
  상세 창은 그대로 뜨고, 그 칸 위에 어두운 막과 금빛 **"장착"**(장비) / **"사용"**(크리스탈)
  글자를 얹는다(`act` 겹 · `_show_cell_action`). 글자는 상세 창 단추(`_bag_action`)와
  같고, 다시 누르면 `_on_bag_action` 을 그대로 부른다 — 두 길이 같은 판정을 탄다.
  **가방 칸에만** 얹는다: 장비 창 칸(해제)과 크리스탈 대상 고르기 중에는 얹지 않는다.
  - **막과 배지는 칸 높이를 다 받는다**(`size_flags_vertical = SIZE_FILL`). ★ 칸이
    `PanelContainer` 라 안 주면 Label 이 글자 높이(27px)로 **가운데 띠**가 된다. 그래서
    막이 칸 가운데만 가려 그림 위쪽이 잘려 보였고, 오른쪽 아래여야 할 강화 배지가 오른쪽
    가운데에 떠서 "장착" 과 붙어 **"장착3"** 으로 읽혔다 (2026-09-26, 찍어서 봤다).
    `ui_test` 가 막 높이를 잰다.
- **착용 레벨이 모자라면 "레벨 부족" 을 붉게 띄우고 단추를 끈다** (2026-09-23). 칸 글자·
  단추·상세 창의 `착용 Lv.N` 줄이 붉어지고(`INV_WARN`), 칸을 다시 눌러도 끼지 않는다.
  판정의 `Items.can_equip` 과 같은 식으로 미리 본다. **왜** — 테스트 창(`debug_gear`)과
  옛 저장은 레벨을 안 보고 끼워 줘서, 그렇게 낀 반지를 벗으면 다시 못 낀다. 전에는
  "장착" 이 켜진 채라 눌러도 아무 일이 없어 보였다 (사용자 제보: "원래 반지를 다시
  끼려는데 장착이 안 돼").
  위에서부터 등급 이름 · 이름(+강화) · `슬롯 · 착용 Lv.N` · 보유 중/착용 중 · 큰 칸,
  "아이템 정보" 아래에 `등급 · 보유 수량 · 기본 능력치 · 옵션` 을 이름/값
  두 칸 표(`_detail_info`)로 적는다 — 옵션은 **`1차 옵션` · `2차 옵션` · `3차 옵션`** 으로
  차수를 붙여 적는다(2차가 없으면 "크리스탈로 붙임", 3차는 "비어 있음"). 장비를 고르면
  크리스탈 칸을 고르면 등급 대신 "재료" 를 적고 단추가 **"사용"** 이 된다 — 누르면 상세 창
  자리에 **크리스탈 강화 창**이 뜨고 장비 칸을 눌러 대상을 고른다 → [items.md](items.md)
  "옵션 차수와 크리스탈". **이름과 등급은 등급 색**이다(`_grade_tint` —
  표의 흙빛에서 **색상은 그대로 두고 밝기만 올린다** — 채팅창과 같은 `ChatLog.grade_text_color`.
  2026-09-23 까지는 흰색을 30% 섞어서 등급끼리 옅어져 비슷해 보였다). 장착/해제 단추는 이 창 맨 아래다.
  **`강화 +N` 줄은 뺐다** (2026-09-23 요청) — 강화는 이름 뒤 `+N` 과 **칸 오른쪽 아래
  배지**로 보인다. 상세 창 큰 칸의 배지는 글자를 키웠다(22).
  대신 단추 줄에 **"강화"** 가 "장착/해제" 왼쪽에 서고, 누르면 화면 가운데에 **강화 팝업**이
  뜬다 — 성공률·파괴는 거기 적는다 (2026-09-23) → [items.md](items.md) "강화".
- **옛 옵션 이름** — 저장된 옛 아이템에 남은 공격력·방어력 옵션은 표에 없어 `defense +12`
  처럼 영어 키가 찍혔다. `legacyOptionLabel`(shared 의 `LEGACY_OPTION_LABEL`)로 한글을
  찍는다. **판정은 이 옵션을 세지 않는다** (여섯 종으로 다시 지을 때 빠졌다).
- **등급은 칸 테 색이 말한다.** 칸 안쪽에 등급 색 가는 선을 두르고(`grade` 겹),
  배지에서는 등급 숫자를 뺐다 — 배지는 `+강화` · `x개수` 만.
- **고른 칸은 금테를 덮는다** (`pick` 겹 — 받은 그림처럼). 예전의 밝게 하기(modulate)는 없앴다.
- **정렬** 단추는 판정에 `sortBag` 을 보낸다 — 등급 높은 것 → 슬롯 순서 → 강화 높은 것.
- 장착 6칸은 캐릭터를 사이에 두고 **세 칸씩 세로로** 세운다 (`_gear_cells` — 격자가 아니라 목록이다).
- 스탯 여섯(`STAT_NAMES`)은 장비 창 아래 상자에 2열 세 줄.
- **캐릭터 정보 창** (2026-09-26 요청: "기본 공격력 / 공격력 증가 % / 최종 공격력 이렇게
  디테일하게"). `_build_char_panel` · `_build_char_window` · `_redraw_char`.
  - **따로 뜨는 창이고, 오른쪽 위 메뉴 맨 앞 "정보" 단추로 연다** (같은 날 요청: "상세
    정보창을 따로 띄우고 버튼을 만들어"). 처음엔 장비 창 스탯 상자 아래 "상세" 로 상세 창
    자리를 번갈아 썼는데, 그 단추는 뺐다. 창은 **화면 가운데**(`CenterContainer`)다.
  - **가방 창들과 번갈아 뜬다.** 가운데 창이 상세 창 자리(인벤토리 왼쪽)를 덮는다 —
    정보를 열면 가방이 닫히고, 가방·크리스탈 단추를 누르면 정보 창이 닫힌다.

  - 공격력·방어력·체력(`CHAR_SPLIT`)은 **기본 → 증가 → 최종** 세 줄씩, 나머지(치명타 ·
    치명타 피해 · 공격 속도 · 쿨타임 감소 · 방어력 관통)는 한 줄씩. 맨 아래에

  뒤에 자리를 다시 잡는다.

  옵션이 다르면 성능이 다르므로 겹치지 않는다.
- 칸이 작아 이름을 다 못 쓴다. 이름·능력치·버튼은 **아래 상세 칸**에서 보여준다.
- 배지: 등급 숫자 / `+N` 강화 / 개수.
- 상세 칸의 옵션 칩은 `title` 로 `N등급 범위 min~max` 를 보여준다.
  잘 뽑은 물건인지 알 수 있어야 등급을 올릴 이유가 생긴다.
- **요약 줄**(`.bag-gear-sum`)은 상태바에 안 나오는 것만 적는다 —
  치명타 / 치명타 데미지 / 공격 속도. 옵션으로만 붙는 값이라 여기가 없으면
  무엇을 끼웠는지 알 방법이 없다.

  건틀릿만이었고 2026-09-26 에 여섯 부위 전부로 넓혔다).

  `offhand.png`(방패)는 슬롯을 없애면서 같이 뺐다.

  안 돌린 사람도 창은 돌아가야 한다 (모델이 없으면 기둥으로 그리는 것과 같은 규칙).
- **있는지는 `.png` 또는 `.png.import` 가 있는지로 본다.** ★★ 두 번 틀린 자리다:

  | 방법 | PC(에셋 있음) | PC(sync 안 함) | 웹 익스포트 |
  |---|---|---|---|
  | `ResourceLoader.exists` | 있다 | 없다 | **없다고 한다** — 폰에서 전부 글자로 나왔다 |
  | 안 거르고 `load` | 있다 | **오류 쏟아짐** | 있다 |
  | `.png` 또는 `.png.import` | 있다 | 없다 | 있다 |

  익스포트에서 PNG 는 `.ctex` 로 구워져 들어가고 원본 `.png` 는 빠지는데
  **`.png.import` 는 팩에 그대로 들어간다.** `load` 는 리맵을 따라가므로 임포트 파일이
  있으면 불러도 된다. 바닥(`.ktx2`)은 임포트를 안 거쳐 원본이 그대로 있어서 예전
  방식이 거기서는 통했다. 찾은 결과는 이름마다 기억해 둔다.
- 바르코가 준 원본은 **배경이 검은 것과 흰 것이 섞여 있다.** 그대로 쓰면 어두운 창에서
  흰 사각형이 번쩍이므로 굽는 단계에서 걷어낸다. 걷는 방법이 까다로워 세 번 고쳤다:
  밝기로 자르면 동전 속이 비고, 모서리 색만 보면 둥근 사각형 배경(반지·벨트·검)이
  안 걷히고, 겹을 무조건 세 번 벗기면 동전이 통째로 지워졌다(100%). 지금은
  **테두리에서 색을 모아 이어진 것만 걷고, 첫 겹이 25% 미만일 때만 한 겹 더** 들어간다.

### 서버
- 인벤토리는 **본인에게만** `inventory` 메시지로 보낸다 (상태 스키마에 없음).

## 손댈 때

- 아이템에 필드를 더하면 `stackKey` 에 넣을지 판단할 것. 성능이 달라지는
  필드인데 안 넣으면 다른 물건이 한 칸에 겹쳐 보인다.
- 슬롯을 추가하면 `EQUIP_SLOTS`, `SLOT_CODE`, `bonusFor`, `FIXED_SLOT_LABEL`,
  아이콘, 창 격자를 같이 봐야 한다. 칸 이름은 `slotLabels`·`offhandNames` 로
  `items.json` 에 나가므로 `npm run export:godot` 을 다시 돌린다.
- **닫기는 창 오른쪽 위 X 하나다** (2026-09-20 요청 — 모든 창이 같다). 아래쪽
  "닫기" 글자 단추는 지웠고, 남은 단추는 **장착/해제** 하나뿐이다
  (`_close_button` → [ui-art-style.md](ui-art-style.md)).
- **아직 기능은 안 붙였다.** 창·칸·아이콘·고르기·장착/해제까지다. 겹치기(`stackKey`),
  옵션 칩의 등급 범위 안내는 웹 클라에 있던 것이고 고도에는 아직 없다.
  (200칸 스크롤은 된다 — 위 "칸 목록은 끌어서 내린다")
